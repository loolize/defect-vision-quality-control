## О проекте
Выходной визуальный контроль заполненности блистера таблетками до передачи упаковки на следующий производственный этап. На снимке проверяется наличие таблетки в каждой ячейке. Система показывает предварительный результат, а контролер подтверждает решение о дальнейшем маршруте блистера

## Планируемые инструменты
Visual Studio Code, Python, Git, SQLite
