# Объектно-ориентированная реализация (КТ3)

## Назначение программы
Программа предназначена для проверки заполненности ячеек блистера таблетками на основе компьютерного зрения

Реализованы следующие операции:
1. загрузка изображения;
2. проверка качества изображения;
3. применение шаблона расположения ячеек;
4. определение заполненности ячеек;
5. формирование предварительного заключения;
6. подтверждение и сохранение результата проверки

При невозможности автоматического анализа предусмотрена ручная проверка оператором

## Средства разработки

- Java 21 (OpenJDK 21.0.12.1 LTS);
- Apache Maven 3.10.2;
- OpenCV 4.9.0;
- Gson 2.13.1;
- Visual Studio Code


## Сборка и запуск
Команды выполняются из корневой папки репозитория
Сборка:

```bash
mvn -f src/java/pom.xml compile
```

Запуск:

```bash
mvn -q -f src/java/pom.xml exec:java -Dexec.mainClass=Main
```

## Входные данные

- src/template.json: шаблон расположения 18 ячеек
- src/images/blister.png: изображение блистера


Для использования стандартного изображения необходимо нажать Enter при запросе пути к файл

## Пример выполнения

Входные данные: стандартное изображение блистера, имя оператора, подтверждение результата (да), разбор специалистом (нет)

Ожидаемый результат:
- количество ячеек: 18
- заполненные ячейки: 16
- пустые ячейки: 7 и 10
- неопределенные ячейки: отсутствуют
- предварительное заключение: Обнаружена пустая ячейка
- итоговое заключение: Обнаружена пустая ячейка

## Выходные данные

Результаты сохраняются в следующих файлах:

- src/inspection_java.json;
- src/images/inspection_image_java.png

Выходные файлы процедурной версии не перезаписываются

## Особенности реализации

Используются наследование, инкапсуляция, полиморфизм, интерфейс InspectionMethod и коллекции List, ArrayList, Map

Результаты двух алгоритмов совпадают с результатами процедурной реализации на Python при использовании одинаковых входных данных
